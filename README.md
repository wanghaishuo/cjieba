# cjieba

cjieba 是“结巴”（Jieba）中文分词的 C 语言实现版本，专注于高效、轻量的分词服务。

## 特点

- **支持中英文分词**：同时处理中文与英文文本，准确识别词语边界。
- **两种分词模式**：
    - **精确模式**：将句子最精确地切分，适合文本分析。
    - **全模式**：扫描出所有可能的词语，速度更快，但可能存在歧义。
- **内存占用极低**：加载 58 万词词典仅占用约 10 MB 内存。
- **分词性能卓越**：实测分词速度可达 16.39 KB/ms。

## 快速开始

### 环境要求

当前版本仅支持 Linux 系统，需要以下工具：

- C++ 编译器（g++ 4.1+ 或 clang++）
- CMake（2.6+）

### 下载与首次编译

```sh
# 克隆仓库
git clone https://github.com/wanghaishuo/cjieba.git
cd cjieba

# 初始化子模块
git submodule init
git submodule update

# 配置环境（只需执行一次）
source env.sh --install

# 编译项目
sh build.sh
```
编译完成后，可执行文件将生成在 build/ 目录下。

运行示例程序：

./build/demo

### 性能测试

以下性能数据在 **WSL（Ubuntu 20.04.6 LTS，内核 6.6.87.2-microsoft-standard-WSL2）** 环境中测得，硬件配置为：

- CPU: AMD Ryzen 7 9700X 8-Core Processor（虚拟化 16 核）

- 内存: 15 GB（WSL 分配）

- 磁盘: WD_BLACK SN7100 2TB

| 分词器   | 词典大小 | 内存占用 | 分词性能   |
|----------|----------|----------|------------|
| cjieba   | 58 万词  | 10 MB     | 16.39 KB/ms |
| cppjieba | 58 万词  | 200+ MB  | 4.01 KB/ms  |
