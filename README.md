# cjieba

## 简介

cjieba是"结巴(Jieba)"中文分词的C版本

### 主要能力

支持中英文分词，包含精确模式与全模式，内存占用低（58w词的词典，占用8MB内存），分词性能高（16.3913 KB/ms）

## 快速开始

### 环境要求

当前仅支持linux
- C++ 编译器：
  - g++ (推荐 4.1 以上版本)
  - 或 clang++
- cmake (推荐 2.6 以上版本)

### 下载与首次编译

```sh
git clone https://github.com/wanghaishuo/cjieba.git
cd cjieba
git submodule init
git submodule update

sh build.sh
```

### 性能测试

测试环境：
WSL 内部虚拟硬件
- CPU: AMD Ryzen 7 9700X 8-Core Processor (虚拟化 16 核)
- 内存: 15Gi (WSL 分配 15GB)
- 磁盘: 1863GB WD_BLACK SN7100 2TB
- WSL 版本: Ubuntu 20.04.6 LTS (内核 6.6.87.2-microsoft-standard-WSL2)

cjieba
- 58w词的词典，占用8MB内存
- 分词性能16.3913 KB/ms

cppjieba
- 58w词的词典，占用200MB+内存
- 分词性能4.01343 KB/ms
